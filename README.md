# Epiphysics

**An open research program for representations, recursive systems, and predictions grounded in dated evidence.**

Epimechanics proposes a mathematical language for how representations change. Epiphysics tests which representations predict and explain observed systems, and at what cost. General applicability, Lagrangian optimality, and predictive advantage remain questions to investigate; a useful formalism is not by itself empirical validation.

## What exists

The theory, applications, and experimental work are an evolving research archive. Individual claims and experiments need their own evidence status; there is no project-wide claim of validation. Conditional mathematical results must retain their assumptions. In particular, the Lagrangian structure is a substantive structural postulate, not a general established consequence of representability.

The new local engine captures source bytes and revisions, freezes information snapshots, records representation hypotheses and binary forecasts before deadlines, and scores later outcomes with retained corrections. A bounded cycle collects configured sources and records a constant-probability baseline. It makes no AI calls and spends no model budget. The public worked example is synthetic and demonstrates the software only.

Learned entity boundaries, isolated model comparisons, independent timestamp witnesses, robust uncertainty estimates, and value-exchange integrations are planned components. Neither future AI-company dominance nor a universal predictive advantage is assumed.

## Development

```sh
npm install
npm run dev
npm run build
npm run test:engine
```

The site uses Next.js and deploys through the existing Vercel workflow. Content is prepared during development and production builds. The engine uses Python 3.10+ and the standard library. See [DAILY_LOOP.md](DAILY_LOOP.md) for bounded autonomous work and [TODO.md](TODO.md) for the prioritized queue. Preserve other contributors' work and follow the managed worktree workflow.

## Contributing

Inspect a record, reproduce a result, or propose a test with a stated failure condition. Share the source and resolution trail with a result. Keep definitions, postulates, inferred relationships, empirical findings, and conjectures distinct. Do not optimize an evaluator using its final holdout outcomes.
