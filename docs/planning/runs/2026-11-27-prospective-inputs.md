This bounded packet adds the [raw-input contract](../prospective-inputs.md) and one pure adapter for the proposed two-family representation pilot. It binds supplied question, release, acceptance and source bytes to normalized typed assertions for the existing saved-view encoders. It does not consume any actual cohort or prior failed trial, collect a release, register a study, issue a forecast, resolve quality/outcomes or schedule work.

The adapter checks retained byte hashes/lengths/completeness and explicit local time claims, preserves all admitted prior release samples and draft/prerelease IDs, distinguishes invalid/missing openings from valid empty openings, and retains optional publisher values with attribution and precision. Obligation controls bind exact source bytes, Git blob identity, path, acceptance direction, channel and declared quality parameters. Caller receipt claims remain distinct from independently witnessed execution. Source selection and complete schedule authenticity remain external binding requirements.
